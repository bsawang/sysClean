# SysClean — C 盘空间清理工具设计文档

- **日期**: 2026-06-04
- **状态**: 设计稿 v1
- **技术栈**: Python 3.9 + Flask + HTMX + SSE + Lucide Icons

---

## 1. 项目概述

SysClean 是一个面向 Windows 的本地 C 盘空间清理工具，以 Claude Code Skill 形式存在。用户通过浏览器访问 Web UI，选择分类进行扫描，实时查看进度，最终选择并确认清理项。

### 核心原则

- **不做真实操作直到用户确认** — 所有删除操作前必须二次确认
- **每项标注风险** — 每条清理项附带风险等级和具体说明
- **实时反馈** — 扫描和清理过程 SSE 实时推送进度
- **安全优先** — 默认移至回收站、文件锁检查、错误恢复

| **Windows 8.1** | ⚠️ 部分兼容 | 基本功能可用，SSE 需 IE11+/Chrome |

| 版本 | 兼容性 | 说明 |

| **Python 3.9** ~ **3.13** | ✅ 完全兼容 | 当前系统为 3.9 |
| **Python 3.8** | ✅ 兼容 | 需注意 `pathlib` 用法 |

| 浏览器 | 兼容性 | 说明 |
|--------|:------:|------|
| **Chrome 80+** | ✅ 完全兼容 | SSE + HTMX 完美支持 |
| **Edge 80+** | ✅ 完全兼容 | Chromium 内核 |
| **Firefox 78+** | ✅ 完全兼容 | SSE 原生支持 |

### 权限要求

| 操作 | 所需权限 | 说明 |
|------|:--------:|------|
| 读取磁盘信息 | **普通用户** | `psutil.disk_usage()` 无需管理员 |
| 扫描用户目录 | **普通用户** | AppData、Temp 等可读 |
| 扫描系统目录 | **管理员推荐** | 部分系统目录需提权读取 |
| **执行清理** | **管理员推荐** | 临时文件清理需管理员权限以保证完整释放 |
| 进程监控 | **普通用户** | psutil 基本功能可用 |

### 存储兼容性

| 文件系统 | 兼容性 | 说明 |
|----------|:------:|------|
| **NTFS** | ✅ 完全兼容 | 主目标文件系统 |

## 2. 技术栈

| 层 | 技术 | 理由 |
|----|------|------|
| 后端 | **Python 3.9 + Flask** | 系统已预装，零额外安装 |
| 实时推送 | **SSE (Server-Sent Events)** | 单向推送，比 WebSocket 轻量，Flask 原生支持 |
| 前端交互 | **HTMX** | 无需 JS 框架，HTML 属性驱动动态加载 |
| 图标 | **Lucide Icons** (SVG inline) | 单色线条图标，风格统一 |
| 进程监控 | **psutil** | 跨平台进程/磁盘监控 |
| 样式 | 纯 CSS (Github Dark 主题) | 无依赖，单文件 |

## 3. 业务流程

```
① 勾选分类 → ② 开始扫描 → ③ 实时进度 → ④ 查看结果
                                                ↓
⑥ 完成报告 ← ⑤ 清理进度 ← 二次确认 ← 勾选清理项
```

### 3.1 用户操作流程

1. **主界面**: 用户勾选需要扫描的分类（临时文件、系统缓存、安装残留等），点击"开始扫描"
2. **扫描进度**: 实时显示进度条、已扫描目录数、已发现可清理空间、实时发现列表
3. **扫描结果**: 按分类分组展示所有可清理项，每项包含路径、大小、风险标签、具体风险说明
4. **勾选清理项**: 用户逐项勾选或全选，点击"清理选中"
5. **确认对话框**: 模态弹窗列出待清理清单及风险等级，确认后执行
6. **清理进度**: 逐项清理，展示已完成/处理中/等待中的状态
7. **完成报告**: 展示释放空间总量、磁盘状态变化对比、清理明细

## 4. 前端设计

### 4.1 界面布局

- **左侧栏** (220px): 磁盘状态卡片 + 扫描分类勾选列表 + 风险图例
- **右侧内容区**: 根据状态切换显示不同视图

### 4.2 六个核心视图

| # | 视图 | 关键内容 |
|:-:|------|---------|
| 1 | **主界面** | 磁盘状态 (98%) + 6 个分类勾选框 + 开始按钮 |
| 2 | **扫描进度** | 4 步指示器 + 进度条 + 3 列统计 + 实时发现列表 |
| 3 | **扫描结果** | 分类折叠组 + 每项：勾选框、路径、风险标签、风险说明 + 全选/反选/清理按钮 |
| 4 | **确认清理** | 模态遮罩 + 待删清单（含风险标签）+ 不可撤销警告 |
| 5 | **清理进度** | 已释放/已完成统计 + 逐项状态列表（✅/⏳/⭕） |
| 6 | **完成报告** | 释放大数字 + 磁盘对比 (98%→94%) + 清理明细 |

### 4.3 扫描结果条目结构

每行包含：
```
[勾选框] [文件图标] 文件路径          [风险标签]  文件大小
         [风险图标] 具体风险说明文字
         ──────────────────────────────────────── 分隔线
```

### 4.4 风险等级

| 等级 | 标签色 | 含义 | 示例 |
|:----:|:------:|------|------|
| 安全 | 🟢 绿色 | 可放心删除 | 临时文件、安装缓存、显卡缓存 |
| 注意 | 🟡 黄色 | 确认后再删 | 大文件、应用配置缓存 |
| 高风险 | 🔴 红色 | 谨慎操作 | 系统目录、关键进程文件 |

## 5. 后端设计

### 5.1 Flask 路由

| 方法 | 路由 | 功能 |
|------|------|------|
| `GET` | `/` | 主页面 |
| `POST` | `/scan/start` | 启动扫描 `{categories: [...]}` |
| `GET` | `/scan/progress` | SSE 扫描进度流 |
| `GET` | `/scan/results` | 获取扫描结果 |
| `POST` | `/clean/start` | 执行清理 `{items: [ids]}` |
| `GET` | `/clean/progress` | SSE 清理进度流 |
| `GET` | `/processes` | 当前进程列表 |

### 5.2 扫描引擎

```
ScannerEngine
├── scan_temp()      → C:\Windows\Temp, %TEMP%
├── scan_cache()     → NVIDIA DXCache, GLCache, Windows 更新缓存
├── scan_browser()   → Chrome, Edge 缓存
├── scan_installer() → *-updater\installer.exe 等
├── scan_recycle()   → $RECYCLE.BIN
├── scan_large()     → >100MB 的大文件
├── scan_software()  → 已安装软件列表
└── get_processes()  → psutil 进程监控
```

每个扫描器均为 **Generator**，逐条 `yield` 发现项到 SSE 流。

### 5.3 SSE 事件格式

```json
// 进度事件
{"type": "progress", "category": "temp", "percent": 37, "current_file": "C:\\..."}

// 发现事件
{"type": "found", "path": "C:\\...", "size": 1800000000, "risk": "safe", "desc": "系统临时文件，可安全删除"}

// 完成事件
{"type": "complete", "total_size": 7900000000, "total_items": 165}
```

### 5.4 风险判定规则

基于路径模式匹配，规则可配置：

| 模式 | 风险等级 | 说明 |
|------|:--------:|------|
| `*\Temp\*` | 安全 | 系统临时文件 |
| `*\DXCache\*` | 安全 | NVIDIA 缓存，自动重建 |
| `*\*updater\installer.exe` | 安全 | 安装器缓存 |
| `*\npm-cache\*` | 安全 | 包管理缓存 |
| `*\pip\cache\*` | 安全 | Python 包缓存 |
| `*\.vscode\extensions\*` | 注意 | 编辑器扩展 |
| `*\JianyingPro\User Data\*` | 注意 | 应用数据，可能需保留 |
| `*\Windows\System32\*` | 高风险 | 系统文件，禁止操作 |

### 5.5 安全机制

1. **文件锁检查**: 正在被进程使用的文件跳过不删
2. **回收站优先**: 默认 `shell.SHFileOperation` 移至回收站
3. **二次确认**: 确认弹窗列出所有待删项
4. **幂等清理**: 文件已被删则跳过
5. **错误恢复**: 单文件失败不影响后续，记录日志
6. **进程保护**: 不终止系统关键进程

## 7. Skill 文件 (sysclean.md) 结构

Skill 文件是 Claude Code 的指令文件，告诉 Claude 如何操作这个工具：

```markdown
# SysClean Skill

## Description
C 盘空间清理工具，通过 Web UI 选择分类扫描并清理

## Usage
1. 运行 `pip install -r requirements.txt` 安装依赖
2. 运行 `python app.py` 启动服务
3. 引导用户打开浏览器访问 http://localhost:5000
4. 指导用户选择分类、扫描、勾选、确认清理
5. 清理完成后展示结果

## Safety Rules
- 必须等待用户二次确认后才能执行清理
- 所有删除操作前展示完整清单
- 不操作核心系统目录
```
